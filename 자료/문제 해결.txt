문제 해결

1. 애니메이션은 한 함수에 정리하도록 하자
각 메서드에서 개별적으로 애니메이션을 재생하면 서로 다른 애니메이션이 연속해서 실행되어 의도하지 않은 애니메이션 전환이 발생할 수 있다.

2. new는 반복되는 구간에 사용하지 않는다.
new를 사용한다면 메모리를 소비하기 때문에 최소한으로 사용하도록 한다.

3. 안정적인 물리 연산을 위해 MovePosition()를 통하여 움직이는 오브젝트를 만들고자 하였으나, 움직임이 끊겨보이는 현상이 발생해 transform.position을 이용해 이동시켰다.

4. 코요테타임을 적용 후 땅에서 점프키를 연타하면 3단 점프가 되는 상황 발생
원인: 점프 후 발 밑쪽에 있는 콜리전과 땅이 닿아 공중에서 is_ground가 되는 현상 발견
해결: is_jump변수를 추가하여 점프를 누른 경우 코요테 타임이 0으로 변하도록 수정함. 또한 이전 프레임의 is_ground가 false(공중일 때)이며 현재 프레임의 is_ground가 true(지상일 때) 라면 is_jump를 false로 초기화시킴.

5. 적과 플레이어는 서로 충돌하지 않지만, 벽과 땅은 충돌하도록 하기 위해 Layer Collision Matrix설정

6. text의 내용을 변경하면 texteffect가 이미 진행되는 상황 발생. -> text오브젝트를 여러개 만들어 사용

7. 플레이어가 이동중에 낑기는 현상 발생 -> composite collision 사용

8. 토네이도 중복으로 부딫힘. -> 쿨타임을 만들어 해결

9. 상호작용 오브젝트가 다른 씬으로 복붙시 실행되지 않음.
플레이어 리지드바디의 sleep모드를 start awake에서 never sleep으로 변경하니 해결.

10. 최적화를 위해 tag확인시 ==대신 compare 사용

11. 몬스터의 공격과 플레이어의 공격이 맞닿았을 때, 패링이 발동되도록 만들고싶음. 그러나 몬스터의 히트박스 콜리더 안에 플레이어의 콜리더와 플레이어의 어택 콜리더가 함께 들어올 경우 연산의 우선순위가 애매해지는 상황 발생.
-> IsTouching을 통해 플레이어 어택 히트박스부터 우선적으로 연산하도록 만듦.

12. 부동소수점 오류로 인해 캐릭터가 정지해있는 상태에서 x이동속도가 0이 아닌 -4.218847E-15와 같은 0과 가까운 소수가 나오는 현상 발생
-> 애니메이션 변수 run을 속도!=0이 아닌 속도 > 0.01f 형태로 변경함.

13. 스턴을 구현하기 위해 enemystun인터페이스를 생성하여 활용함.

14. 원거리 공격을 하는 보스의 경우 플레이어의 flipX의 값에 따라 공격을 회전하도록 만들면 플레이어의 반대편에 공격하는 경우가 생길 수 있음
-> 플레이어와 보스의 x좌표를 확인하여 올바른 방향으로 공격하도록 수정

15. 보스 점프공격시 점프시 플레이어의 위치까지 이동하도록 만들기
-> 플레이어와 보스의 거리를 구한 뒤 보스의 점프 후 낙하 시간까지를 측정. 거리 / 낙하시간 = 속도 를 통해 속도를 지정함.

16. 보스의 대시 공격 경고가 나타나고 사라지는걸 이미지의 fill amount를 통해 구현함.

17. 플레이어의 데이터를 JSON으로 저장함.

18. 메모리 누수 방지를 위해 -= 를 사용

19. Find를 통해 서능 저하
-> ObjectFindManager를 이용해 캐싱하여 해결.

20. 로그를 사용시 로그함수와 같이 급격히 커지고, 작아지는 현상 발생.
볼륨을 조절할 때 lerp(선형 보간)을 활용하여 설정함.
